# Archived upstream automation

These are historical VoiceStudio GitHub Actions workflows, moved outside
`.github/workflows/` so GitHub cannot execute them in SpeechNexa. They include
release, registry, store, installer smoke, CLA, identity, and scheduled
automation whose owners,
credentials, product names, or destinations belong to upstream. Do not copy one
back without reviewing every trigger, permission, endpoint, artifact name,
signing identity, and publishing target for SpeechNexa.
